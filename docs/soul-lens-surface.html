The shop hover card, with its economy strip

This page runs the shipped overlay script, panorama/scripts/soul_lens.js, against a DOM stand-in for the game's panel API and the baked catalogue in data/items.json. It is the browser witness for the same code the mod packs: each card is filled by the script, not by the page. Glass Cannon is the worked example — Haze's own win/loss rows give its WPA, and every row names the source it came from.

what each line is, and what it refuses

powersouls per +1% weapon power, from the item's BaseAttackDamagePercent and WeaponPower.
wpasouls per +1 percentage point of win probability added: the item's win rate for this hero minus the hero's own win rate, from the recorded wins and losses. Rows under the sample floor print their count and refuse the figure.
dpssouls per +1% DPS of the hero's current weapon, from (1 + power/100) × (1 + fire rate/100) − 1.
buy ≈measured average purchase time across the matches the public API holds, not a recommendation.
in this listthe item's place in the shop list that is open, read from the shop's own panels.
statlockerWPA and build order join the strip only when an X-API-Key answer is present; otherwise the line says why it is absent.
